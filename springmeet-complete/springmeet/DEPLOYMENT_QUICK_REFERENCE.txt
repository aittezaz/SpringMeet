
## 🔐 Step 3: Environment Variables

Generate these before deploying:

```bash
# Generate passwords and secrets (run on your local machine)
openssl rand -hex 16   # For POSTGRES_PASSWORD
openssl rand -hex 16   # For REDIS_PASSWORD
openssl rand -hex 64   # For JWT_SECRET
openssl rand -hex 64   # For JWT_REFRESH_SECRET

# Get Gmail App Password
# 1. Go to https://myaccount.google.com/apppasswords
# 2. Select Mail → Other → SpringMeet
# 3. Copy the 16-character password
```

---

## 🚀 Step 4: Deploy (10 minutes)

### SSH to Server
```bash
ssh root@YOUR_SERVER_IP
```

### Clone & Configure
```bash
cd /opt
git clone https://github.com/YOUR_USERNAME/springmeet.git
cd springmeet

# Edit environment
cp .env.example .env
nano .env  # Or: vi .env
```

### Fill in .env
```env
POSTGRES_PASSWORD=<your_generated_password>
REDIS_PASSWORD=<your_generated_password>
JWT_SECRET=<your_generated_64_char_hex>
JWT_REFRESH_SECRET=<your_generated_64_char_hex>
SMTP_USER=your-email@gmail.com
SMTP_PASS=<your_gmail_app_password>
FRONTEND_URL=https://yourdomain.com
NEXT_PUBLIC_API_URL=https://api.yourdomain.com
NEXT_PUBLIC_SOCKET_URL=https://api.yourdomain.com
NEXT_PUBLIC_APP_URL=https://yourdomain.com
```

### Update Nginx
```bash
sed -i 's/yourdomain.com/YOUR_ACTUAL_DOMAIN.com/g' nginx/nginx.conf
```

### Deploy!
```bash
bash deploy.sh
```

⏱️ **Wait 3-5 minutes** for services to start

## 🆘 Troubleshooting (Quick)

| Problem | Solution |
|---------|----------|
| API not responding | `docker compose logs backend` |
| Blank frontend page | `docker compose logs frontend` |
| SSL certificate error | Wait 5 min, check `docker compose logs certbot` |
| Database won't connect | Check `.env` DATABASE_URL, wait 30 sec |
| Services not starting | `docker compose restart` |
